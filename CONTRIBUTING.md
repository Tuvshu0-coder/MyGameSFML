# Contributing

Thanks for taking the time to contribute!

## Prerequisites
- Visual Studio 2022
- C++17 toolset (v143)
- SFML (bin/include/lib) available under `External/`

## Build
1. Open the solution in Visual Studio.
2. Select `Release|x64` or `Debug|x64`.
3. Build the solution.

## Code Style
- Use tabs for indentation.
- Keep files in CRLF line endings.
- Prefer clear, small functions and early returns.

## Assets
- Place runtime assets under `Assets/`.
- Update references in code if asset paths change.

## Pull Requests
- Keep changes focused and described.
- Ensure the game runs from the output folder with assets and SFML DLLs.
