# Get Your Bugatti Back!

A 2D pixel-art action platformer where you hunt down three monsters to recover your stolen Bugatti.

## Introduction

This project is a thrilling 2D pixel-art action platformer that combines engaging sword combat with platforming challenges. Players will navigate through three unique levels, battling enemies and solving puzzles to reclaim their stolen Bugatti.

## Features
- Sword combat with combos and blocking
- 3 levels with platforming and enemies
- Dialog, UI, and ending credits

## Installation

To get started with the project, follow these installation instructions:

1. Ensure you have Visual Studio 2022 installed.
2. Clone the repository to your local machine.
3. Open the solution in Visual Studio 2022.
4. Select `Release|x64` or `Debug|x64` configuration.
5. Build the solution.

## Usage

To run the game, follow these steps:

1. Copy the `Assets/` folder next to the output `.exe`.
2. Copy the correct SFML DLLs next to the `.exe`.
3. Launch the game by double-clicking the `.exe` file.

### Controls
- `A/D` Move
- `LShift` Run
- `Space` Jump
- `J` Attack
- `K` Block
- `E` Interact
- `P` Pause

## Asset Requirements

When guidance references UI text or fonts, ensure the project includes a font file under `Assets/Fonts` and that the runtime working directory is `$(ProjectDir)`. If text fails to render, verify the font path and file name match exactly.
